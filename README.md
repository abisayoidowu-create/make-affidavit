## Overview

Creating an affidavit can be time-consuming, especially when you need to ensure that:

- Important facts are presented in the correct order.
- Statements are clear and easy to understand.
- Required personal and legal details are included.
- The final document has a professional structure.

Make Affidavits aims to provide a straightforward experience for:

1. Individuals preparing personal declarations.
2. Professionals assisting clients with affidavit preparation.
3. Organizations managing recurring document workflows.
4. Developers building affidavit-related services and integrations.

---

## Why Make Affidavits?

Traditional affidavit preparation can involve:

- Repetitive manual formatting
  - Rewriting similar statements
  - Reorganizing sections
  - Correcting inconsistent details
- Unclear document structures
  - Missing information
  - Poorly ordered facts
  - Difficult-to-read declarations
- Time-consuming revisions
  - Editing multiple versions
  - Rechecking names and dates
  - Preparing documents for review

Make Affidavits brings these steps into one focused workflow so users can spend less time formatting and more time verifying the information that matters.

## How It Works

The typical workflow is designed to be simple:

1. **Choose an affidavit type**
   - Personal declaration
   - Address declaration
   - Name declaration
   - Relationship declaration
   - Custom affidavit
2. **Enter the required details**
   - Full name
   - Address
   - Relevant dates
   - Supporting facts
   - Additional parties or witnesses
3. **Review the generated document**
   - Check spelling and dates
   - Confirm that all statements are accurate
   - Add or remove sections where necessary
4. **Export or share**
   - Download the completed affidavit
   - Send it for professional review
   - Prepare it for witnessing or notarization where applicable

## Getting Started

### Prerequisites

Before running the project locally, ensure you have:

- A supported operating system
- Git installed
- The required runtime for this project
- A package manager such as `npm`, `pnpm`, `yarn`, or `pip`

### Installation

Clone the repository and install its dependencies:

```bash
git clone https://github.com/your-username/make-affidavits.git
cd make-affidavits

# Replace this command with the package manager used by the project
npm install

# Start the development server
npm run dev
```

Open the local application at the development URL shown in your terminal.
